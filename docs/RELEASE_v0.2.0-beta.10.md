# WakeLink v0.2.0-beta.10

Public prerelease for testing. Install over an existing PC Power Free or WakeLink installation without uninstalling or re-pairing.

## Windows

- Left-click the tray icon to open WakeLink. Right-click it for the existing menu.
- Check for updates from the tray or dashboard. The tray asks before opening the Windows installer download; it never runs the installer automatically.
- The guided dashboard, optional desktop shortcut and Windows certificate-permission repair from the beta.9 local preview are included.
- Existing port, token, machine identity, TLS certificate/key, guard state and Home Assistant pairing are retained during upgrade.

## Other downloads

The Home Assistant integration ZIP, experimental Linux source bundle and experimental DSM package are included at the same version. The Home Assistant protocol is unchanged. The Windows installer remains unsigned; actual PC power actions, Alexa/Matter and real hardware upgrades are not yet fully validated.

[English and Spanish update steps](https://github.com/slx612/WOL-Home-Assistant-And-Alexa/blob/v0.2.0-beta.10/docs/WINDOWS-beta.10.md)

## Espanol

Version preliminar publica para pruebas. Instala encima de PC Power Free o WakeLink sin desinstalar ni volver a vincular.

- Clic izquierdo en el icono de la bandeja: abre WakeLink. Clic derecho: muestra el menu habitual.
- Buscar actualizaciones desde la bandeja o el panel. La bandeja pregunta antes de abrir la descarga del instalador; nunca lo ejecuta automaticamente.
- Incluye el panel guiado, el acceso de escritorio opcional y la correccion de permisos del certificado de la vista previa local beta.9.
- Conserva puerto, token, identidad del PC, certificado/clave TLS, proteccion y vinculacion de Home Assistant.
- Se incluyen el ZIP de Home Assistant, el paquete fuente Linux y el paquete DSM experimentales con la misma version. El protocolo de Home Assistant no cambia. El instalador Windows sigue sin firma digital; faltan pruebas completas de energia, Alexa/Matter y actualizaciones en hardware real.
